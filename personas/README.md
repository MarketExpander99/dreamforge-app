# Skill-Gain Personas System

This folder contains the distributed operating personas for everyone working on Skill-Gain (humans and agents).

## How to use

Load the relevant persona(s) into your coding agent / Cursor / Cline / Grok session before starting work.

- Always start from `00-BASE.md` (or ensure the agent has already absorbed it).
- Then load the specialist persona that matches the current task.
- For large or cross-cutting work, also load `01-OVERWATCH.md`.

Example:
> "Load personas/00-BASE.md and personas/03-UI-CSS.md. We are fixing mobile navigation contrast."

## Core Doctrine (non-negotiable)

1. **Mission**: Free, premium-quality, Grok-guided education that makes children more capable and agentic.
2. **AI Interaction Layer**: Every subject and learning path must structurally include how AI transforms that domain — what becomes scarce, what becomes leverage, what remains irreplaceably human.
3. **Agency first**: We do not train kids for jobs that AI is already replacing. We train them to direct AI, exercise judgement, create, and reinvent themselves.
4. **Choice**: Pure human-mode paths remain available where warranted.
5. **Forward domains**: Space industry, orbital data centres, multiplanetary work, and emerging fields are first-class citizens in the knowledge lattice.
6. **Quality gate**: Does this increase the child’s agency and ability to leverage AI, or is it preparing them for obsolescence?
